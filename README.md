# SCT_WD_3

# SkillCraft Technology - Task 3

## Quiz Game Application

This project is developed as part of the SkillCraft Technology Web Development Internship.

## Features

- Interactive Quiz Game
- 10 Multiple Choice Questions
- Previous Question Navigation
- Next Question Navigation
- Skip Question Option
- Progress Bar
- Dynamic Question Loading
- Automatic Score Calculation
- Result Dashboard
- Correct, Wrong and Skipped Question Count
- Performance Message with Emoji
- Restart Quiz Option
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Folder Structure

```text
SCT_WD_3

```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.



## Project Output

The Quiz Game Application allows users to:

- Answer 10 multiple-choice questions
- Navigate using Previous and Next buttons
- Skip any question
- Track quiz progress using the progress bar
- Submit the quiz to view results
- View total score and percentage
- See the number of correct, wrong and skipped answers
- Receive a performance message with an emoji
- Restart the quiz and play again
